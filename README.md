# FouraEthiopia 🌍📚

FouraEthiopia is an all-in-one educational platform for Ethiopian university students.  
It offers access to:

- 📘 Study notes, tutorials, PDFs, and sample exams  
- ✅ Multiple-choice quizzes with instant results  
- 🏆 Leaderboard & star rewards system  
- 👨‍🏫 Subjects for both Natural and Social science streams  
- 📅 Event calendar for academic events  
- 💬 Real-time chat, forums & feedback system  
- 🔐 Secure login with payment verification  
- 🧑‍🎓 Mentor matching and profile rewards  
- 📩 Notifications, live sessions & analytics dashboard
